# IEI Student Chapter - Department of Information Technology
### MGM's College of Engineering, Nanded

Official modern Linktree and web hub built with **React**, **Vite**, and **Tailwind CSS**, based on the Google Stitch UI design (`projects/9625211837219846932`).

---

## 🚀 Quick Start

### 1. Install dependencies:
```bash
npm install
```

### 2. Run local development server:
```bash
npm run dev
```

### 3. Build for production:
```bash
npm run build
```
